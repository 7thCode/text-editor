# テキストエディター

Wails プラットフォームで構築された、Svelte と Google Material Design を使用したモダンなテキストエディターです。

## 機能

### File メニュー

- **新規作成**: 空のファイルを新規作成
- **開く**: 既存のテキストファイルを開く
- **保存**: 現在のファイルを保存
- **名前を付けて保存**: 新しいファイル名で保存

### Edit メニュー

- **元に戻す**: 直前の操作を元に戻す
- **切り取り**: 選択したテキストを切り取り
- **コピー**: 選択したテキストをコピー
- **貼り付け**: クリップボードの内容を貼り付け

### その他の機能

- **キーボードショートカット**: 効率的な操作
- **Material Design UI**: 美しく使いやすいインターフェース
- **日本語対応**: 完全な日本語サポート
- **変更状態の表示**: ファイルの変更状態を視覚的に表示

## 対応ファイル形式

- テキストファイル (\*.txt)
- Markdown ファイル (\*.md)
- JavaScript ファイル (\*.js)
- Python ファイル (\*.py)
- HTML ファイル (\*.html)
- CSS ファイル (\*.css)
- JSON ファイル (\*.json)
- その他のテキストファイル

## キーボードショートカット

### File メニュー

| ショートカット                      | 機能             |
| ----------------------------------- | ---------------- |
| `Ctrl+N` (Mac: `Cmd+N`)             | 新規ファイル作成 |
| `Ctrl+O` (Mac: `Cmd+O`)             | ファイルを開く   |
| `Ctrl+S` (Mac: `Cmd+S`)             | 保存             |
| `Ctrl+Shift+S` (Mac: `Cmd+Shift+S`) | 名前を付けて保存 |

### Edit メニュー

| ショートカット          | 機能     |
| ----------------------- | -------- |
| `Ctrl+Z` (Mac: `Cmd+Z`) | 元に戻す |
| `Ctrl+X` (Mac: `Cmd+X`) | 切り取り |
| `Ctrl+C` (Mac: `Cmd+C`) | コピー   |
| `Ctrl+V` (Mac: `Cmd+V`) | 貼り付け |

## 開発環境のセットアップ

### 前提条件

- Go 1.18 以上
- Node.js 16 以上
- Wails CLI v2

### インストール

1. リポジトリをクローン

```bash
git clone <repository-url>
cd text-editor
```

2. フロントエンドの依存関係をインストール

```bash
cd frontend
npm install
cd ..
```

3. アプリケーションをビルド

```bash
wails build
```

### 開発モードでの実行

```bash
wails dev
```

### 本番ビルド

```bash
wails build
```

## 技術スタック

### バックエンド

- **Go**: メインアプリケーションロジック
- **Wails v2**: デスクトップアプリケーションフレームワーク

### フロントエンド

- **Svelte**: リアクティブな UI フレームワーク
- **Material Design Web Components**: Google Material Design
- **Vite**: 高速なビルドツール

## プロジェクト構造

```
│   ├── index.html      # HTMLテンプレート
│   └── package.json    # 依存関係
└── build/              # ビルド出力
```
